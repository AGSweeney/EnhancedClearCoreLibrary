# ClearCoreROS has moved

ClearCoreROS (ClearCore firmware that exposes M0-M3 as ROS 2 joints, with its host tools and ROS 2
packages) now lives in its own repository:

**https://github.com/AGSweeney/ClearCore_ROS**

It uses this library as a git submodule (`external/EnhancedClearCoreLibrary`). The code that was
here, up to the split, is in this repository's history.
